# Contributing

Contributions should make a reproduction decision more inspectable, not merely more automated.

Before proposing a change:

1. Reproduce the behavior with a small, public or fictional fixture.
2. Remove private data, credentials, unpublished results, and licensed source text.
3. Add a regression test that records the expected claim status.
4. Explain whether the change affects evidence status, execution boundaries, metric comparison, or report privacy.

Do not submit restricted datasets, credentials, paywalled papers, or instructions that bypass access controls.
